# 백엔드·추천·AI 연결 검증

검증일: 2026-10-21. 실제 사용자 정보 없이 가상 설문 선택지와 공개 상품만 사용했다. 이 기록은 서비스 동작 검사이며 임상 검증이나 독립 제2검수를 의미하지 않는다.

## 자동 검사

- Python 백엔드 시나리오 **26개 통과**: SQLite/화면 내보내기87개 일치, 보류 품번·SQL 인자, 관심/예산/제형, 특화 기능 제외, 위험/모름 조건, 기존 제품 중복, 단위·하루 기준·부등호, RAG 질의, 동의·만료·철회, 요청 제한, AI 미설정, Agent 다단계 도구 계약, 위조 출처·제품·수치 거부, AI 기한, 제공자 정보 최소화, 개인정보 형식 로컬 제한.
- 프런트엔드 **10개 통과**: 기존8개와 서버 기동 대기·준비 후 자동 진행·전체 기한/재시도 상태2개.
- TypeScript 검사 및 프로덕션 빌드 통과.
- `git diff --check` 통과. 실제 `.env`가 Git 추적되지 않고 제외 규칙에 해당함을 확인. Git 업로드 대상 파일 및 프런트 빌드에서 실제 키 문자열 없음 확인.

테스트의 Agent 대역은 외부 비용 없이 계약과 오류를 확인하기 위한 것이며 실제 AI 접속 성공과 구별했다. 테스트 클라이언트 의존성의 비차단 사용 중단 예정 경고1종이 있으나 검사 실패는 없다.

## 실제 공급자 검사

[연결 검사 기록](gemini-live-check.json)은 실제 키를 서버 환경변수로 읽어 공개 마그네슘 제품 설명을 생성한 결과다. 키 값·프롬프트 원문·사용자 개인정보를 기록하지 않는다.

- Gemini 3.8 Flash에서도 실제 도구 실행·인용 검증을 확인했다(당시 약31초).
- 상품 정보 설명용 Gemini 3.5 Flash Lite로 같은 검증을 통과했고 단독 검사에서 약2.6초였다.
- 최종 공급자 응답은 실제 DB에서 조회한 필드 ID와 상품을 기준으로 재검증한다.
- 두 번의 함수 선택 단계와 실제 선택 가능한 여러 함수, 검색된 근거의 결합은 코드·계약 검사로 확인한다. 명시 제품에 충분한 근거가 있으면 추가 선택 호출을 생략한다.

속도는 단일 로컬 실행 사례이며 동시 사용자 부하나 무료 호스팅 첫 기동 성능 보장이 아니다. Google 응답 형식의 지원 범위에 맞춰 최소 JSON 스키마를 보내고 서버에서 더 엄격한 검증을 수행하도록 실제 요청 오류를 수정했다.

## 실제 HTTP 검사

[최종 API 실행 기록](backend-live-check.json): 로컬8000 서버에 동의→상품87개→보류404→추천+실제Gemini→비교→중복→추천제한→정보부족→실제AI대화→철회→이전연결401을 확인했다.

최종 장 건강 예시 후보는 올비텐 유산균(`034345002`), 락토핏 골드(`591580521`), 유한 프리바이오틱스(`600651647`)였다. 성별·혈당·간 건강 등 추가 개인 조건이 필요한 특화 제품이 일반 후보에 섞이지 않도록 표시 기능정보까지 확인하는 회귀를 추가했다.

최종 HTTP 사례의 추천·AI 설명은 약3.7초, 제품 대화는 약2.5초였다. 실제 값은 JSON 기록을 기준으로 한다.

## 브라우저 확인

기존4173 미리보기 프로세스는 유지하고 로컬8000 API로 직접 연결했다.

- 동의3개 확인→실제 서버 세션→5단계 설문→장 건강 후보3개와 Gemini 설명·출처가 표시됨을 확인.
- 제품 상세→제품 맥락이 있는 AI 대화 전송을 확인.
- 결과·설문 수정·실제 추천 제한·기존 제품 정보 부족·동의 철회 및 입력 없는 직접 URL 상태를 확인했다.
- 실제 사용자 테스트나 모바일 실기기 부하 검사는 아직 진행하지 않았다.

화면 기록은 `docs/screenshots/live-*.png`에 있다. 이전 정적 프런트엔드·썸네일 단계의 기록은 해당 문서의 당시 상태이며 현재 실제 API 연결 결과와 구별한다.

# 영양제 첫걸음 화면·흐름 설계

2026-10-21 백엔드 연결 반영. 모바일 360~430px 우선, 데스크톱 대응. 빨강·흰색 중심의 독립 브랜드이며 다이소 공식 로고를 사용하지 않는다.

## 화면

| 화면 | 구성·행동 | 오류·정보 부족 |
|---|---|---|
| 홈 `#/` | 짧은 소개→설문/AI 진입→공식 사진 제품 예시→표시 읽기 안내 | 서버 준비 시 기동 안내·자동 재확인·실패 재시도. 홈 제품은 개인 추천으로 표시하지 않음 |
| 안내·동의 | 성인 범위·서버 처리·Gemini 전송·외부 처리 조건·3개 확인 | 서버에서도 동의 버전·필수 확인 검사. 일반 제품 탐색은 동의 없이 가능 |
| 설문 `#/survey/1..5` | 관심·식습관·기존 제품·주의조건·예산/제형. 이전/다음과 선택 항목 건너뛰기 | 누락·배타 선택·기존 제품 미선택 차단. 기존 제품 최대10개. 모름·목록 밖을 구분 |
| 결과 `#/results` | 입력 요약→기존 제품 중복→후보 최대3개→선정 이유·원문→AI 설명·대화 연결 | 실제 서버 상태로 정상/없음/정보 부족/제한/호출 오류 구분. 부족한 설문 단계로 돌아감. AI 오류는 정책 결과와 구분 |
| 목록 `#/catalog` | DB 검수87개 검색·식품유형 필터·가격·사진·비교 담기 | 검색 결과 없음·서버 연결 실패. 보류 품번 제외 |
| 상세 `#/products/:id` | 공식 사진→유형·관찰가·포장→성분·기준량→섭취법·주의·알레르기·보관→원료·출처 | 없는/보류 품번404. 표시 부재를0으로 표현하지 않음. 사진 실패는 대체 안내 |
| 비교 `#/compare` | 두 제품 슬롯·검색·추가·교체→서버 표시 비교→차이만 보기 | 두 개 미만 안내·세 번째 교체 모달·조회 실패 재시도. 다른 단위·기준은 자동 우열 판단하지 않음 |
| AI `#/chat` | 동의 후 질문·최근 대화·선택 제품·근거 펼치기·상세 연결 | 빈 입력/300자 제한·중복 전송 차단·실패 재시도·초기화. 의료·개인정보 질문은 서버 안내. 실제 AI가 없으면 오류 안내 |

홈·목록·상세·비교는 바로 접근할 수 있다. 개인 조건이 필요한 추천·AI는 동의 후 사용한다. 추천 결과에 직접 접근하거나 새로고침하면 입력 없음 상태가 나온다. `state` 쿼리로 고정 예시나 오류를 실제 결과처럼 강제하는 기존 데모 기능은 제거했다.

## 편의와 접근성

- 모바일 하단 홈·추천·비교·AI 메뉴, 제품 탐색 중 비교 바. 설문·대화에서는 바를 숨겨 입력 공간 확보.
- 선택 상태는 색 외 아이콘·문구·접근성 상태로도 표시. 큰 주요 버튼, 레이블·오류·키보드 포커스·모달 취소 제공.
- 두 제품을 같은 항목 아래 나란히 표시해 모바일 가로 스크롤을 피함.
- 긴 원료·인용은 펼치고 필수 주의사항은 바로 확인할 수 있게 함.
- 원문 정량·섭취법과 AI가 생성한 정성 설명을 구분함. AI 답변에는 출처 원문을 펼쳐 확인하는 연결 제공.
- 동의 철회 버튼은 입력·대화·제품 맥락과 임시 연결을 초기화. 만료시 재동의 안내.

## 사진과 데이터

공식 썸네일 88개를 확보하고 검수 완료 87개만 화면에 제공한다. 공통 사진 컴포넌트가 전체 포장을 보이게 비율을 유지하고 실패·미확보를 구분한다. 사진 관찰일(2026-10-21), 가격 관찰일(2026-10-19), 표시 검수일을 별도로 관리한다. 상세 사진·성분표 원본·OCR·검수 원장은 프런트 번들에 포함하지 않는다.

실행 중 제품은 `services.ts`의 HTTP 어댑터가 DB에서 가져온다. 기존 정적 상품 JSON은 형식·재현 검사에 남으며 실제 추천이나 조회의 대체 데이터로 사용하지 않는다.

## 정보 처리와 연결

브라우저 메모리에 입력을 보관하며 localStorage를 사용하지 않는다. 설문은 서버에서 처리하고 Gemini에는 일반 질문·제한된 최근 대화·관심/예산/제형 및 공개 제품 근거를 전달한다. 주의조건·식습관·기존 복용 내역은 서버에서만 검사한다. 외부 제공자 처리 조건은 동의 화면에서 별도 안내한다.

프런트는 서버와 독립적으로 열리고 기동 대기를 안내한다. 자동 확인 전체75초 이내, 한 요청5초 기한, 준비 후 자동 진행, 실패시 재시도. API 키는 프런트나 공개 환경변수에 넣지 않는다.

## AI 상담가 확장

AI 대화는 성분·식사·보관·일반 주의정보를 설명한다. 시작 화면에 근거가 연결된 질문6개를 제공하며 선택 제품이 있으면 해당 제품 질문을 먼저 제시한다. 일반 안내와 제품 원문 출처를 구분하고, 개인정보·개인 복용 판단은 확인 안내로 처리한다. 자세한 구현 범위와 검증은 [AI 상담가 문서](ai-counselor.md)를 참고한다.

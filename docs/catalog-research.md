# 다이소 건강식품 카탈로그 브라우저 조사

관찰일: 2026-10-19 (Asia/Seoul). 기존 3개 파일럿은 전체 목록이 아닌 수집·검수 방식 검증용 표본이다. 이번에는 목록 식별을 넓혀 조사했다. **현재 게시된 건강식품 탐색 표본이며, 전체 영양제 목록이나 추천 검수완료 목록이 아니다.**

## 조사 결과와 집계 정의

- 공식 건강식품 카테고리에서 가격이 붙은 카드 124회, 서로 다른 상품번호 105개를 읽었다. 같은 번호의 반복 노출 19회를 확인했다. 이미지 링크와 가격 링크를 각각 새 상품으로 세지 않았다.
- 그중 비타민·미네랄·유산균·건강식품 비교에 관련된 단품 88개 SKU를 저장했다. 17개는 주로 즙·오일·차·의약외품 등으로 이번 저장 표본에서 제외했다. 포함된 88개에도 일반식품과 유형 미확인 상품이 있으므로 ‘영양제 88종’ 또는 ‘건강기능식품 88종’이라고 표현하면 안 된다.
- 상품명에 나타난 브랜드/회사/협업 표기를 묶은 탐색 그룹은 17개다. 이는 제조공장 17곳이라는 뜻이 아니며 회사와 하위 브랜드가 섞인 집계다. 종근당과 종근당건강은 분리했다. 올비텐은 카드에 회사가 없으므로 안국약품으로 임의 병합하지 않았다.
- 포장 수량과 표시 일수를 제거한 제품군은 85개로 추정된다. 대웅제약 마그네슘 10정/30정, 비타민D 4000IU 10정/30정, 멀티비타민미네랄 6정/30정의 세 쌍만 같은 제품군으로 합쳤다. 성분명만 같다고 다른 브랜드·제형을 합치지 않았다. 배합 동일성을 라벨로 검증한 집계는 아니다.
- 유산균 검색에서 12개·8개 묶음 상품을 별도로 확인했고 4개 예시를 JSON의 `excluded_bundle_examples`에 저장했다. 신규 제품군 수에 넣지 않았다. 이 4개는 카테고리 단품 88개와 별도다.
- 현재 전국 매장 재고·구매 가능 여부는 집계하지 않았다. 게시와 표시가격만 확인했다. 가격은 배송비와 카드 혜택 제외이며 관찰 시점 이후 바뀔 수 있다.

## 조사 경로

1. [다이소몰 홈](https://www.daisomall.co.kr/ds)에서 건강식품 링크를 확인하고 [건강식품 카테고리](https://www.daisomall.co.kr/ds/diy2/C246)를 열었다. 신상·기초건강·장/간건강 등 화면의 상품 카드와 공식 상세 링크의 `pdNo`를 읽었다. 비공개 API 호출이나 접근제어 우회를 사용하지 않았다.
2. 사이트 검색창으로 ‘유산균’, ‘비타민’을 검색했다. 유산균 47개에는 반려동물과 일반식품·묶음이 섞였고, 비타민 269개에는 화장품 등 비식품도 섞였다. 두 검색 총건수는 영양제 수로 쓰지 않았다. 검색 목록은 일부 로딩된 범위를 확인했으며 끝까지 전수 수집하지 않았다.
3. 제조사 공식 페이지로 출시 시점과 유형 구분을 교차확인했다. 현재 가격은 과거 발표가가 아니라 다이소몰 카드에서 가져왔다.
4. LG생활건강 비눌린 워터믹스의 상세 화면을 추가로 열어 품번·가격·옵션과 브랜드 링크를 확인했다. 나머지는 이번 조사에서 목록 카드 확인이며, 기존 파일럿 3개는 별도로 상세 근거가 남아 있다. JSON에서 둘을 구분했다.

## 중복·변형 처리와 재검수

- 상세 SKU 키는 문자열 `product_number`다. `032...`처럼 앞자리가 0인 번호를 정수로 바꾸지 않았다. `recmYn` 같은 추천 추적 매개변수는 제거하고 관찰한 `pdNo`를 보존했다.
- 반복 카드 19회는 124회 전체 관찰 범위의 중복이며, 저장한 88개만의 중복 수가 아니다. 제외된 17개는 삭제·품절 상품이 아니라 이번 표본 밖 항목이다.
- 10정/30정은 SKU로는 따로 두고 추정 제품군에서만 합쳤다. 구미·정제·액상, 단일 비타민D·비타민D+아연, 프라임도스·일반 리포좀 제품은 서로 합치지 않았다.
- 4병/5병·7포 등 포장 안의 구성 수는 단품 규격이다. 8개/12개 소비자 포장을 다시 묶은 도매형 카드만 별도 묶음 예시로 분류했다.
- 기능성·함량·주의사항 전수 수집을 이번 목록 조사로 대체하지 않았다. 모든 행은 `discovery_only`, `recommendation_eligible=false`다. 기존 파일럿 eligibility도 변경하지 않았다.
- 자체 재검수로 SKU 중복, 공식 URL 호스트, 번호와 URL 일치, CSV/JSON 행수, 브랜드·제품군 집계를 확인했다. 독립 제2검수는 없었다.

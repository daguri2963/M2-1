## 필드별 추적

`data/products/pilot-products.json`의 각 필드는 `value`(정규화), `raw`(짧은 원문 또는 발췌 표시), `source_url`, `accessed_on`, `status`, `reason`, `method`를 가진다.

- 상품명·품번·가격·채널: 공식 다이소몰 상품 화면.
- 포장·제조원·유통전문판매원·식품 유형·주요 원료·함량·섭취방법·주의사항·우유 함유: 각 상품의 공식 상세 이미지. 이미지 URL도 필드에 남겼다.
- 마그네슘: 화면에서 PRODUCT INFORMATION의 제조·판매원, 함량, 섭취방법, 주의사항을 직접 판독했다. 이미지 대체 텍스트는 비어 있었다.
- 비타민B·칼슘: 이미지 대체 텍스트를 확보했다. 텍스트의 줄바꿈 때문에 제조원/판매원 항목이 뒤섞여 보이는 부분이 있어 포장 상단의 판매원/제조원 표기와 대조했다. 라벨 전수 시각 대조는 미완료로 명시했다.
- 기능성분은 1일 섭취량 기준이다. 마그네슘 제품 1정 1,000mg은 정제 전체 중량이고 마그네슘 315mg과 다르다. 칼슘 제품의 700mg은 4정 기준이며 1정 기준으로 바꾸지 않았다.
- 원료명 목록은 일부 식별만 했고 전체 원료명 필드는 null이다. 우유 함유 확인만으로 교차오염 알레르기 정보가 완성된 것은 아니다.

## 제조사 자체 자료 접근 결과

[대웅제약 공식 발표](https://www.daewoong.co.kr/ko/newsroom/news/6273)의 제목은 ‘대웅제약X다이소, 국민 건강 프로젝트 닥터베어 26종 출시’로 확인했다. 웹 본문과 브라우저에서 기사 내용·발행일은 확보하지 못했다. 제목을 개별 SKU의 함량이나 현재 판매가 근거로 사용하지 않았다.

[대웅제약 공식몰 닥터베어 분류](https://m.dwhcmall.com/product/list_gallery.html?cate_no=266&page=1)는 조회 결과 상품 0개였다. 공식몰 검색에서 닥터베어 EX 마그네슘 관련 과거 리뷰도 나왔으나 다이소의 닥터베어 1,000mg × 30정과 동일 변형임을 입증하지 못해 합치지 않았다. 리뷰와 비공식 판매자의 숫자는 데이터에 사용하지 않았다.

다이소 상세에 표시된 제조원은 마그네슘: 대웅제약 1공장, 비타민B: 코스맥스바이오, 칼슘: 이앤에스다. 브랜드/유통전문판매원인 대웅제약을 모든 제품의 제조원으로 간주하지 않았다. 제조사 자체 사이트와의 정확한 포장·신고번호 연결은 세 제품 모두 미확정이다.

## 접근성과 미확인 상태

웹 조회 도구의 다이소몰 홈 열기는 Internal Error를 반환했다. 일반 브라우저 첫 접속은 시간 초과였지만 생성된 탭은 정상 로딩되어 사이트 검색과 상세 화면에서 조사할 수 있었다. 접근제어 우회나 비공개 API는 사용하지 않았다. 고시 표가 ‘상세페이지 참조’인 경우 그 문구를 실제 성분값으로 취급하지 않았다.

자료 게시·갱신일은 미표시이므로 null이다. CDN URL의 날짜는 파일 경로일 뿐 발행·개정일로 쓰지 않는다. 조회일은 게시일과 분리한다. 상세 이미지 전체와 구매자 리뷰는 저장·재게시하지 않았다.

## 다음 보완 자료

1. 각 상품의 동일 품번·포장 최신 라벨 앞뒤(원료/영양기능/섭취/주의/제조판매/신고번호)와 제조사 공식 제품 URL을 확보한다.
2. 비타민B·칼슘 대체 텍스트를 실제 이미지와 전수 대조한다. 마그네슘도 전체 원료와 교차오염 문구를 보완한다.
3. 품목제조신고번호가 확보되면 식품안전나라 공식 신고정보와 연결한다. 이력추적번호·바코드를 신고번호 대신 넣지 않는다.
4. 다른 팀원이 재검수하고 가격·라벨 최신성을 확인한 뒤에만 추천 대상 승격 여부를 결정한다.

사용자가 보완할 경우 위 세 공식 상품 URL에 대응하는 읽을 수 있는 최신 라벨만 있으면 된다. 동일 브랜드의 다른 포장 라벨로 대체하지 않는다.

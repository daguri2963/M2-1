## 브라우저

로컬 화면에서도 다음 동작을 직접 확인했다. API 검사와 별개로 화면에서 새 추천과 질문을 요청해 실제 GPT 응답이 표시되는 것을 확인했다.

- 코디세이·OpenAI 전송 안내와 필수 동의 → 설문 5단계 → 준비 상태 → 후보 3개와 AI 선택 근거 표시.
- 추천 결과에서 두 제품 비교 담기 → 비교 화면에서 해당 제품·사진·표시정보 표 확인.
- 설문 관심 분야가 AI 화면에 전달되고 GPT·코디세이 API 표시 확인.
- 제품 미선택 상태에서 ‘함량과 기준량의 차이’ 질문 → AI 답변과 공식 안내 출처 버튼 표시. 기존 AI_NO_EVIDENCE 문제 재현되지 않음.
- 제품 찾기에서 87개 조회 → ‘칼슘 마그네슘’ 검색으로 1개 필터 → 제품 상세의 사진·성분·섭취방법·주의사항·확인일 표시.
- 동의 철회 시 홈으로 이동하고 동의 철회 버튼·개인 설문·대화 세션 초기화.

개별 응답 시간은 이 로컬 실행의 관찰값이며 SLA나 모든 질문의 성공을 보장하지 않는다. 의학적 정확성에 대한 외부 검수나 실사용자 5명 피드백과는 별개다. 운영 서버의 환경변수나 배포는 이번 검사에서 변경하지 않았다.

작업 절차는 **canary 로컬 검증 → canary→dev PR 및 필수 CI → dev 통합**으로 갱신했다. 병합 중 충돌 해결·추가 변경이 있다면 영향을 받은 로컬 검사를 다시 수행한다.

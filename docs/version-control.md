## 제외 항목

`.gitignore`로 아래 항목을 제외하며 로컬 파일 자체는 삭제하지 않는다.

- `frontend/node_modules/`, `frontend/dist/`, TypeScript 빌드 캐시. `npm ci`, `npm run build`로 재생성한다.
- OS 파일, Python 캐시, 로그·임시 파일.
- `.env` 실값, 개인용 `.codex/`·`.agents/`·`.aws/` 설정. 안전한 `.env.example`은 추적할 수 있다.
- 성공한 `.ocr.json`으로 대체된 `.ocr.error.txt` 21개. 수집·재시도 이력은 대장에 보존한다.
- `58-official-package-screen.txt`: 제품 외 공개 리뷰까지 들어 있는 전체 화면 접근성 덤프. 해당 공식 화면 PNG·SHA256·URL·관찰일과 12정 포장 검수값은 포함한다.

## 용량과 점검

최초 점검 시 대상 전체는 약 268 MiB, 가장 큰 파일은 SQLite 약 11.3 MiB다. 100 MiB를 초과하는 파일은 없어 일반 Git으로 관리한다. 원본과 검수 이미지는 판독 근거이므로 중복 캐시로 간주해 일괄 제외하지 않는다. 이번 저장에는 Git LFS가 필요하지 않다.

비밀키·API 키·GitHub 토큰 등의 패턴을 검사했고 해당 항목은 발견되지 않았다. 검사 결과에 실제 비밀값을 출력하지 않는다. 개인 건강정보·사용자 테스트 기록은 이번 수록 대상에 없다.

앞서 통과한 서비스·데이터 검사는 Git 저장만을 위해 반복하지 않는다. 커밋 대상·제외 범위·`git diff --check`와 원격 상태를 확인한 후 일반 커밋·푸시를 진행한다.

CSV는 검증 해시와 재생성 결과의 바이트 일치를 위해 원래 CRLF를 보존한다. `.gitattributes`는 CSV의 CRLF와 Markdown의 의도된 두 칸 줄바꿈을 공백 오류로 취급하지 않도록 설정한다. 원본 자료의 내용을 바꾸어 공백 경고를 없애지 않는다.

# 추천 정책 v2026-10-23.2 (운영 반영)

임베딩이나 LLM의 자유 순위 결정이 아니라 검수 표시와 버전 관리된 목적 분류를 사용하는 결정적 제품 탐색 알고리즘이다. 2026-10-23 production 0bc17dc에 반영했다. 현재 제출 기준과 검증은 [AI 설계](final/ai-design.md)·[검증 결과](final/test-results.md)를 함께 확인한다.

## 입력과 분류

관심 분야는 일상의 활력, 뼈·근육 건강, 장 건강, 혈당 관리, 다이어트의 다섯 개이며 복수 선택할 수 있다. 추천 후보를 확보하지 못한 눈 건강과 관심 분야의 ‘잘 모르겠어요’는 UI·API에서 제외했다. 분야 선택이 어려우면 설문 아래 AI 대화 링크로 이동할 수 있다. 식습관·기존 제품·주의조건의 모름 선택은 유지한다. 새로고침하면 입력이 지워지는 기존 방식이며, 이전 관심 값이 포함된 API 요청은 422로 거절한다. ‘다양한 성분 보기’도 지원하지 않는다.

| 입력 | 처리 |
|---|---|
| 관심 | 다섯 관심 분야 중 하나 이상 선택. 상품별 목적 중심 분류 |
| 식습관 | 결핍 추정에 사용하지 않음 |
| 기존 제품 | 최대10개. 같은 표시 성분을 가진 새 후보 제외. 기존 혈당·체지방 기능 제품의 같은 목적 추가도 제한 |
| 주의조건 | 질환 진단·치료·의약품, 임신·수유, 알레르기 확인 필요는 추천 제한. 모름은 정보 부족 |
| 특화 확인 | 혈당·다이어트에 `specialtyConfirmed=true` 필요. 미확인은4단계로 안내 |
| 예산 | 기존 관찰 단품 가격 상한. 실시간 가격·재고 아님 |
| 제형 | 정제·캡슐, 구미·츄어블, 분말·포, 필름·액상. 씹는 제형과 일반 정제를 구분 |

주의조건은 약을 먹지 않더라도 질환 진단·의료진 관리가 필요한 상황을 포함한다. 병명·약품명·검사값은 수집하지 않는다. 이전 ‘의약품 복용·치료 중’ 값도 제한 조건으로만 호환한다.

관심 분류 버전은 `2026-10-23.3`이다. 안전 제한과 혈당·체지방의 검토 범위는 변경하지 않아 정책·`scopeReviewVersion`은 `2026-10-23.2`를 유지한다.

원본 SQLite는 변경하지 않았다. `data/recommendation/classification-v2.json`에28개 상품의40개 성분별 표시 연결을 별도 기록했다. 공개87개 전체와 자동 후보 범위는 다르며, 분류하지 않은 상품도 상세·비교에서는 기존대로 조회한다.

각 연결은 관심 분야, direct/related, 세부 목적, 실제 표시의 원료명·기능 문장, 품번:function ID를 가진다. `backend/classification.py`는 현재 표시의 같은 원료 구간과 문장 일치를 검사한다. 표시가 변경되거나 다른 성분의 기능으로 연결되면 분류를 사용하지 않는다. 루테올린을 루테인으로 부분 문자열 매칭하지 않는다.

- direct: 주요 구성과 기능이 목적에 직접 연결된 탐색 후보. 효능·안전성 우위 점수가 아니다.
- related: 관련 영양소를 포함하지만 기본 추천 후보에 올리지 않는 탐색 정보.
- 보류: 범위 밖·검토 미완료·기존 정량 제한 등으로 자동 후보에서 제외.

활력은 B 중심 제품을 direct로, 마그네슘·일부 종합비타민은 related로 구분했다. 뼈·근육은 두 세부 목적을 설명한다. 장은 프로바이오틱스와 프리바이오틱스의 표시 차이를 보여준다. 눈 건강은 추천 관심 분야에서 제외했다. 해당 성분을 포함한 상품의 원본 표시와 상세·비교 정보는 삭제하지 않았다.

## 제외와 특화 범위

검수 완료 공개 제품만 읽는다. 보류 품번600651654는 조회·비교·추천에서 제외한다. 일반식품, 필수 표시·정확한 하루 기준 정량이 부족한 제품은 자동 후보에서 제외한다. 정량은 부등호가 아닌 `=`과 확인한 단위를 요구한다.

키즈·성별·철분·임산부·월경·전립선·수면·간 건강·혈압 등 미지원 범위와 표시 기준치200% 초과/해석 불가 제한은 유지한다. 200%는 프로젝트 탐색 범위이며 의학적 상한·안전 판정이 아니다.

혈당·체지방 제품은 관심 분야에 포함되고 `scopeReviewVersion`이 정책 버전과 같아야 한다. 명확한 주의조건과 특화 확인도 필요하다. 분류표에 이름이 생겼다는 이유로 개방하지 않는다.

검토한 혈당 상품은 배러 크런치 바나바601678608, 락토핏 당케어591580761, 혈당케어 & 유산균610910678이다. 다이어트는 다이글로핏 다이어트 플러스976195543의 검수된 기능·정량·섭취법·주의사항을 연결했다. 이 범위 검토는 임상적 안전 승인이나 독립 전문가 검수가 아니다.

브이팩 다이어트968235549는 카페인 관련 추가 확인과 기존 비율 제한으로 보류한다. 푸응 슬립앤버닝032306284는 미지원 수면 기능으로 제외한다. 미확인을 카페인 주의 없음으로 간주하거나 다른 미지원 범위를 자동 개방하지 않는다.

등록 제품에 같은 혈당·체지방 기능이 있으면 새 상품의 추가 후보를 제한한다. 원료가 다르다는 이유로 병용 가능이라고 설명하지 않는다.

## 순위와 포장 변형

direct 후보만 기본 목록을 구성한다. 반복적으로 아직 충족하지 못한 관심 분야 수 → 아직 보여주지 않은 세부 목적 수 → 연결되는 선택 분야 수 → 관찰 단품 가격 → 품번 순으로 정한다. 함량·성분 개수·효능·필요량은 점수로 사용하지 않는다. 입력 순서를 바꿔도 같은 후보가 나온다.

수동 대조한 family라도 브랜드·제형·섭취방법·하루 기준 표시 정량이 같아야 대표 하나로 정리한다. 다른 조성이면 합치지 않는다. 대표는 조건을 만족하는 중 단품 관찰 가격이 낮은 규격을 우선하며 하루 비용·약학적 대체성을 의미하지 않는다.

최대 세 개이며 한두 개도 정상이다. 관련 성분 대안을 개수 채우기용으로 승격하지 않는다. 부족한 분야는 `missingInterests`로 설명하고, direct 후보가 없으면 empty다. related는 접힌 별도 탐색 정보로 표시한다.

## API·RAG·정보 처리

기존 응답에 `classificationVersion`, 선정 후보의 `purposeMatches`, 부족한 `missingInterests`, 별도 탐색용 `relatedProducts`, 하위 호환을 위해 빈 배열로 유지하는 `guidance`를 추가했다.

추천 근거 검색은 실제 기능 원문의 출처와 분류에 쓴 `matchedClaims`를 함께 전달한다. GPT에는 선정 후보·목적 연결·부족 분야를 알려주고 다른 성분의 기능 전가와 후보 밖 추천을 막도록 지시한다. JSON·인용·제품·수치·복용 지시는 기존 서버 검사를 유지한다. 문장의 모든 의미 오류를 자동 검출한다고 보장하지 않는다.

주의조건·식습관·기존 복용 내역·`specialtyConfirmed`는 외부 AI로 전송하지 않는다. 관심·예산·제형과 공개 상품·근거만 사용한다. AI 설명 실패가 서버 선정 후보나 제한 상태를 바꾸지 않는다.

기존 중복·단위 규칙을 유지한다. 식사·의약품·미등록 상품은 포함하지 않으며 동일 성분의 g/mg/μg만 질량 환산한다. IU·CFU·RAE·DFE·NE 등은 다른 단위로 자동 변환하지 않는다. 기준·연산자·단위가 불명확하면 합계를 미확인으로 둔다.

식습관만으로 결핍을 추정하거나 개인별 필요량·병용 안전·혈당 수치·감량량을 판정하지 않는다. 질환 치료와 제품 기능 범위 구분의 배경은 [질병관리청 안내](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6548), 상품 연결의 직접 근거는 각 상품의 공식 표시다. 원래 표시 검수일을 이번 정책 작성일로 바꾸지 않는다.

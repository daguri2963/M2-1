# 88개 제품 표시정보 전수 검수 보고

완료일: 2026-10-20 (Asia/Seoul). 기존 카탈로그의 88개 SKU를 유지하고 실제 공식 표시 이미지를 전부 열어 품명·변형·포장, 원재료, 영양·기능성 함량과 기준, 섭취법, 주의사항, 알레르기·같은 제조시설, 보관방법을 대조했다. 같은 수행자의 자체 검수이며 독립 제2검수는 수행하지 않았다.

완료 조건은 실제 시각 대조, 공식 상세와 제품명·변형·포장 매칭, 필수 13항목의 확인 또는 명시적 미표시·해당 없음 사유, 명시적 완료 결정, 미해결 차단 사유 없음이다. 이미지나 OCR 파일이 있다는 이유로 완료 처리하지 않았다. 제조사 자체 사이트의 동일 변형 추가 자료 미확보만으로 보류하지 않았다.

필수 13항목은 제품명, 식품유형, 제조원, 유통판매원, 포장, 제형, 원재료, 영양, 기능, 섭취법, 주의사항, 보관, 알레르기·같은 제조시설이다. 일반식품의 건강기능식품 기능 표시는 해당 없음으로 남기며, 관찰 표에 없는 정보는 null과 사유로 기록했다. 610911097 필름의 영양정보 부재는 성분량 0으로 변환하지 않았다.

## 보완·정정 내용

기존 OCR 후보 655개 정량·1,238개 원료 행은 삭제하지 않고 검수에서 대체·제외된 이력으로 보존했다. 913개 정량 행에는 원문 수량, 단위, 비교연산자, 표시 기준, 영양성분 기준치 비율, 출처를 함께 저장했다. 직접 확인한 새 행과 기존 후보 행을 합쳐 검증 행 수를 부풀리지 않았다.

- 칼슘 600000147: 700 mg의 기준을 4정(3.6 g)으로 유지. 1일 2회×2정의 섭취방법과 연결했다.
- 비타민B 600000129: B12 2.4 μg의 소수점과 단위를 확인했다.
- 판비틴 610911100: 비오틴 70,000 μg의 기준은 총내용량 42 g(14포). 1일량으로 표시하지 않았다.
- LG 레티놀 994953530: 비타민A 12,000 μg RAE는 총 12포 기준이다.
- 032306284: 서로 다른 정제 600 mg·650 mg, Withanoside IV 5.664 mg을 유지했다.
- 976195543: 미리세틴 6.64 mg·루테올린 3.76 mg을 구분했다.
- 994953534: 나트륨·당류·단백질의 ‘미만’ 3개를 `<`로 보존했다.
- 032306212: `50억 CFU`의 원문을 남기고 숫자 표기만 5,000,000,000으로 저장했다. 질량 환산은 하지 않았다.
- 600651647: 프락토올리고당 3 g은 섭취방법상 하루 2포(4 g) 기준이다.
- 032306200: 원본의 1정 600 mg과 공식 판매 화면의 12정 포장을 별도 출처로 연결했다. 화면 관찰일은 2026-10-20이다.

복합팩은 각 제품별 원료·캡슐기제·제형을 구분했고, 같은 브랜드의 다른 용량 제품끼리 원료와 알레르기 목록을 복사하지 않았다. 원료의 괄호 묶음·원산지·순서를 보존했다. 원료 원문에 표시된 비율은 문자열로 남겼으며 미표시 배합량은 추정하지 않았다. 표시되지 않은 하위 원료 계층이나 성분 동의어 체계는 만들지 않았다.

`label-review-corrections.json`과 SQLite `correction_history`는 초기값·현재값·사유·출처·검수일을 제공한다. 단순 누락 보완과 검수 상태 승격도 들어 있으므로 기록 수를 모두 ‘오류 건수’라고 해석하면 안 된다. 초기 데이터와 배치별 판단은 `review-history/`에 보존했다.

## 보류 1개

**600651654 — 산뜻해질 유한 생유산균 캡슐**

공식 하단 제품정보표의 실제 문구가 `프로바이오틱스 수 (수량 기재 안됨)`이다. OCR 누락으로 취급하지 않았다. 같은 공식 상세의 상단 광고에는 1캡슐당 100억 CFU 투입·20억 CFU 보장이 있으므로 해당 광고 크롭과 원문은 별도로 보존했다. 광고값을 영양표의 확정 수량으로 승격하지 않았다.

해소하려면 동일 품번·변형·포장의 수량이 기재된 공식 정정 라벨 또는 제조사 동일 제품의 명확한 공식 표시 자료가 필요하다. 현재 확인된 일반 영양 5행과 다른 표시 필드는 남겨 두고, `verified_product_nutrients`에서는 이 제품 전체를 제외한다. 완결 제품 정량 조회는 908행이며 필드 수준 직접 관찰 조회는 913행이다.

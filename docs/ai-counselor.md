# 영양제 AI 상담가

구현일: 2026-10-21. 기존 상품 설명에 일반 영양 지식과 후속 질문을 결합한다. 실제 약사·의사라는 표현을 사용하지 않고 일반 정보·교육 서비스로 표시한다. 추천 정책과 Must 기능 수는 변경하지 않는다.

## 제공하는 경험

- 핵심 답부터 쉽게 설명하고 필요한 이유·확인점·출처를 이어서 제시한다. 모든 답변에 같은 경고나 제품 선택 요청을 붙이지 않는다.
- 성분 역할, 식사·섭취 시간, 보관, 일반 주의사항과 상호작용의 원리를 설명한다.
- 제품의 가격·함량·섭취방법·보관방법은 기존 검수 SQLite에서 조회한다. 일반 성분 지식을 특정 제품의 효과로 옮기지 않는다.
- 제품 후보 선정과 성분 중복 계산은 기존 서버 정책을 사용한다. 일반 설명 때문에 제품을 임의로 추천하지 않는다.
- ‘그럼 식후에는?’ 같은 후속 질문은 필터링한 최근 일반 대화의 주제를 참고한다.

## 지식과 출처

`backend/nutrition-knowledge.json`은 공식 자료12개, 지식 항목35개, 서로 다른 질문 예시48개를 포함한다. 기존 표시 읽기 안내2개도 유지한다. 주요 성분은 비타민C·D·B12·E, 칼슘·마그네슘·아연·철, 오메가3·프로바이오틱스다.

NIH ODS 성분별 소비자 자료와 식품안전나라의 안전한 섭취방법을 읽고 한국어 요약을 원문과 대조했다. 원문 제목·기관·URL·확인일·짧은 원문 발췌·발췌 해시·적용 범위를 기록한다. `updatedAt=null`은 원문 갱신일을 따로 확정하지 않았다는 뜻이며 확인일로 대체하지 않는다. 미국 권장량·상한 수치와 법적 표시 의무는 국내 정책으로 가져오지 않는다.

일부 사이트의 직접 수집 요청이403을 반환해 원문 전체를 다운로드하지 않았다. 공식 웹 도구로 읽은 내용과 짧은 발췌를 보존한다. 이는 자료와 요약의 대조이며 약사 검토·임상 검증·독립 제2검수는 아니다. 재생성은 `scripts/build_nutrition_knowledge.py`로 수행한다.

출처가 없는 질문이나 커버하지 않은 세부 정보는 추가 질문·확인 안내를 제공한다. 실시간 웹 검색과 새 유료 API는 연결하지 않았다. 향후 확장은 공식 자료 확인과 질문 평가를 거쳐 항목을 추가한다.

## 요청 경로

1. 서버에서 현재 질문의 개인정보·개인 복용 판단·긴급 상황 표현을 먼저 확인한다.
2. 일반 질문은 성분 동의어·질문 주제로 영양 지식을, 제품 질문은 검수 DB를 조회한다.
3. Gemini는 기존 도구와 `search_nutrition_knowledge` 중 필요한 도구를 선택한다. 일반 지식 요청은 지식·근거 검색 도구로 범위를 좁힌다.
4. 관련 근거를 요청별로 조합해 설명을 생성한다. 검증한 출처 ID만 인용하고 URL은 서버가 붙인다.
5. 생성 수치·용량 지시·효과 보장·약사 사칭의 대표 형태를 검사한다. B12·오메가3의 숫자를 용량 숫자와 구별한다. 구체적인 제품 수치는 검수 원문으로 제공한다.

지식은 작은 JSON 자료에서 질의별로 검색한다. 서버에 큰 임베딩 모델을 설치하거나 새로운 DB 서버를 만들지 않아 기존 무료 배포 구조를 유지한다. 공식 일반 지식 출처는 `kind=knowledge`, 상품 ID/상품 URL은 null이며 ‘공식 안내 원문’으로 표시한다.

## 질문 구분과 정보 처리

| 질문 | 처리 |
|---|---|
| 알레르기 표시의 의미·일반 상호작용 원리 | 공식 지식으로 설명 |
| 특정 사람의 질환·복용 약·검사 결과·병용 가능 여부 | 외부 AI 전송 전 서버 안내 |
| 개인 용량 변경·증량 | 서버 안내 |
| 현재 호흡 곤란 등 긴급 상황을 시사하는 대표 표현 | AI 응답을 기다리지 않도록 응급의료기관 도움 안내 |
| 이름·연락처 등 대표 개인정보 형식 | 서버 안내, 외부 AI로 보내지 않음 |
| 근거 부족 | 질문 구체화 안내, HTTP200 |
| 실제 공급자 실패·한도·시간 초과 | 기존 명시적 오류 유지 |

위험·개인정보 판단은 대표 표현에 대한 로컬 규칙이다. 모든 언어·우회 표현·개인정보를 완벽히 탐지하지 못하며 자동 진단 체계가 아니다. 사용자가 실제 건강정보를 적지 않도록 기존 안내를 유지한다. 무료 Gemini의 개인정보·민감정보 전송 제한과 의료 조언 용도 제한을 유지한다. [공급자 이용조건](https://ai.google.dev/gemini-api/terms).

주의조건이 있는 설문을 작성했어도 일반 개념 질문까지 차단하지 않는다. 주의조건·식습관·기존 제품 기록은 Gemini 입력에 넣지 않는다. 과거의 개인 질문과 그에 대한 답변을 대화 문맥에서 제거하고, 이후의 일반 질문은 계속 답할 수 있도록 했다. 모델 자체의 질문 분류를 위해 민감 원문을 먼저 보내지 않는다.

동의 버전은 `2026-10-21.2`다. 서버의 영구 미저장·30분 메모리 세션·철회 방식은 유지한다. 재배포 후 새 동의가 필요할 수 있다.

## 실제 배포 검증

백엔드와 홈페이지를 `b1185bf`로 배포하고 양쪽 `live` 상태를 확인했다. [외부 상담가 검사](counselor-deployment-check.json)에서 공개 일반 질문5개·후속 질문1개가 실제 Gemini 답변과 관련 출처를 반환했다. 가상 개인 복용·긴급 상황·연락처 입력3개는 도구 실행 없이 서버 안내로 처리했다. 이 실행의 일반 질문 응답은 약1.9~2.8초였으며 단일 사례다.

[기존 기능 외부 회귀](counselor-backend-check.json)에서도 상품87개·검수 게이트·실제 추천·비교·중복·제한·정보 부족·표시 읽기·제품 대화·철회를 통과했다. 실제 사용자 건강정보는 사용하지 않았다. 전문가 검토, 모바일 실기기·다중 사용자 부하, 실제 타깃5명 피드백은 별도 단계다.

공개 홈페이지에서도 ‘유산균은 무조건 냉장 보관해야 하나요?’ 질문의 실제 답변과 펼쳐지는 공식 자료 요약·원문 링크·확인일을 확인했다. [상담 화면 기록](screenshots/deployed-counselor.png). 입력 안내는 일반적인 약품명 언급과 개인의 실제 복용 내역을 구별하도록 정리했다.

최종 입력 안내·검증 기록 커밋은 `10656a7`이며 홈페이지 배포 `dep-dbcap55g1s2s738kjvqg`가 `live`임을 확인했다. 백엔드 실행 코드는 `b1185bf`를 유지한다. 이후 검증 문서만의 커밋은 앱 재배포를 일으키지 않는다.

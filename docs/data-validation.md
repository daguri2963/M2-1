## 스키마와 누락 처리

- 제품 식별 키: 내부 `id`와 다이소 `daiso_product_number`. 서로 다른 포장과 묶음은 별도 SKU로 취급한다.
- 필드 `value`는 정규화값, `raw`는 짧은 표시 원문이다. 원료 목록의 raw는 ‘주요 원료명 발췌’라고 표시했으며 전체 원문이 아니다.
- `official_observed`: 공식 화면/이미지에서 관찰. 독립 검수완료라는 의미가 아니다.
- `official_alt_pending_visual`: 공식 이미지의 대체 텍스트를 확보했으나 이미지 시각 대조가 남음.
- `unverified`: 값은 null, 사유 필수. 자료없음과 접근 실패, 제품 매칭 미확정을 구분하여 reason에 기록한다.
- 전체 원료, 신고번호, 제조사 동일 변형 URL, 발행일, 하루 비용은 null이다. 숫자 0이나 빈 문자열로 대체하지 않는다.
- `eligibility`는 다이소 게시 확인, 다이소 SKU 식별, 제조사 자체 동일 변형 매칭, 필수항목 검증을 분리한다. 모든 게이트를 통과하기 전 `recommendation_eligible`을 true로 바꾸지 않는다.
- 문서 발행일은 확인하지 못했다. 이미지 URL 폴더의 날짜는 발행/갱신일 근거가 아니다.

## 자체 재검수 절차와 결과

1. 다이소 검색목록에서 단품과 8/10/12개 묶음이 섞여 있음을 확인하고 단품만 선택했다.
2. 상세 페이지의 상품명, 품번, 표시가, 포장 개수와 링크의 `pdNo`를 대조했다. 10정과 30정 옵션, EX 제품을 병합하지 않았다.
3. 공식 상세 이미지의 표시와 화면 요약을 확인했다. 마그네슘은 직접 라벨을 읽었고 비타민B·칼슘은 대체 텍스트를 확보하여 상태를 낮춰 기록했다.
4. 제조원과 브랜드/유통전문판매원을 분리했다. 비타민B 대체 텍스트는 항목 줄바꿈이 뒤섞여 있어 상단 판매원/제조원 한 줄 표시와 비교했지만 최종 전수 시각 대조는 남겨 뒀다.
5. 1일 섭취량 기준과 단위를 다시 확인했다. 성분량 315mg·700mg을 정제 중량과 혼동하지 않았다.
6. 제조사 자체 사이트는 발표 제목/상품 0개 분류까지만 확보되어 개별 SKU 매칭 근거로 승격시키지 않았다. 공식몰 EX 제품 리뷰도 제외했다.
7. 검증 도구로 JSON 참조·필수 증거 필드·null 사유·양수 함량·단위·섭취 기준·추천 제외 게이트를 검사했다.

실행: `python3 scripts/validate_pilot_products.py`

결과: `PASS: 3 products; 0 recommendation eligible`

이 검사는 파일 내부 정합성을 확인하며 원본이 최신인지, 대체 텍스트가 이미지와 일치하는지, 규제기관 신고와 일치하는지 증명하지 않는다.

## 충돌·보완 기록

- 확정된 수치 충돌은 아직 없다. 서로 다른 공식 라벨 버전을 확보하지 못했으므로 ‘충돌 없음’이 최신성 검증완료를 뜻하지 않는다.
- 마그네슘 상세 고시의 원료/영양/주의 항목은 ‘상세페이지 참조’로 되어 있어 그 표만으로는 완전성 검증 불가다.
- 비타민B·칼슘은 원본 이미지 시각 검수를 완료한 뒤 대체 텍스트의 OCR/줄바꿈 오류를 수정해야 한다.
- 최신 실물 라벨 또는 제조사 공식 동일 변형 자료가 확보되면 날짜와 변경 필드를 기록한다. 기존 증거를 지우거나 조회일을 일괄 새 날짜로 바꾸지 않는다.
- 다음 검수자는 전체 원료, 우유 및 교차오염, 주의사항 전체, 신고번호, 정확한 제조·판매원, SKU/포장, 가격을 확인하고 이름/검수일/차이를 남긴다. 완료 전에는 추천 대상에서 제외한다.

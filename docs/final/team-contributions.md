# 팀원 역할과 실제 기여 증빙

2026-10-24 · [제출 목차](README.md)

팀원은 **이승현·윤준서·배창민·김재욱·조준수**다. 팀 제공 정보에 따라 이승현은 주 개발자, 조준수는 부 개발자로 **프런트엔드·백엔드·AI 추천 개발을 함께 담당**하도록 배정했다. `sayknow`는 이승현의 GitHub 계정임을 확인했다.

## 역할 배정

| 팀원 | 배정 역할 | 상세 책임·협업 | 담당 산출물 위치 |
|---|---|---|---|
| 이승현 | 주 개발·통합/운영 관리 | 화면/API/DB 연결·추천/Agent 핵심 구현·통합 설계·CI·production 승격·배포 관리. 조준수의 개발 작업 통합 | [화면](../../frontend/src/App.tsx), [API](../../backend/main.py), [추천](../../backend/policy.py), [Agent](../../backend/agent.py), [기여 절차](../../CONTRIBUTING.md) |
| 김재욱 | 자료 수집·검수·RAG 자료 정리 | 공식 상품/제조사 출처 확인, 성분·단위·기준·섭취법·주의 정리, 미확인/보류 관리, 일반 영양 자료와 검색어/별칭 정리 | [DB 기록](../product-database.md), [표시 검수](../product-label-review.md), [지식 자료](../../backend/nutrition-knowledge.json) |
| 윤준서 | 기획·요구사항·설계 문서 | 타깃/문제/범위 정의, Must 관리, 화면 흐름·기술 선정 근거·명세와 실제 구현 대조 | [기획서](../project-plan.md), [명세서](../functional-requirements.md), [아키텍처](architecture.md) |
| 배창민 | 테스트·피드백·문서 정리 | Must 시나리오, 타깃 사용자 모집/근거·익명화 원본 정리, 개선 확인, 테스트·진행 기록·발표 내용 취합 | [검증](test-results.md), [피드백](user-feedback.md), [진행 기록](progress.md) |
| 조준수 | 부 개발 | 주 개발자와 프런트/백엔드/AI 추천 공동 개발, 컴포넌트·API 보완, 추천 분류·검색 도구·응답 검증 보조, 오류 재현·회귀 확인 | [화면](../../frontend/src/App.tsx), [API](../../backend/main.py), [분류](../../backend/classification.py), [AI 비교](../../backend/comparison.py), [검사](../../backend/tests/) |

위 산출물은 **담당 범위에 배정한 위치**다. 파일 링크만으로 해당 개인이 실제 작성했다는 증거로 사용하지 않는다. 개발 두 명의 참여는 팀이 확인했지만 세부 작업량·개인별 작성 이력은 별도 확인 대상이다. 나머지 세 명의 세부 역할은 이번 문서 정리 과정의 배정이다.

## 개인별 제출 확인 표

과제의 전원 기여 증빙에는 각자가 실제 수행한 **본인 작성 요약 + 대표 커밋/PR/문서 링크**가 필요하다. 아래 보완 항목은 역할 배정만으로 완료 처리하지 않는다.

| 이름 | 현재 실제 확인 | 개인별 보완 |
|---|---|---|
| 이승현 | 본인 계정 `sayknow` 확인, 위 커밋/PR 링크 확보 | 본인이 작성한 기여 요약·공동 개발 범위 확인 |
| 김재욱 | 자료/RAG 역할 배정 | 실제 수행 내용의 본인 요약·작성 문서/수집 기록/커밋 링크 |
| 윤준서 | 기획/명세 역할 배정 | 실제 수행 내용의 본인 요약·작성 문서/수정 이력 링크 |
| 배창민 | 테스트/피드백/문서 역할 배정 | 실제 수행 내용의 본인 요약·검사/피드백 정리 이력 링크 |
| 조준수 | 부 개발 참여를 팀이 확인 | 실제 담당 기능의 본인 요약·개인 커밋/PR 또는 공동 작업 문서 링크 |

공동 개발이 이승현 계정에서 저장되었다면 각자의 실제 작업 범위를 공동 작업 기록으로 확인하고 관련 변경 링크와 함께 제시한다. 존재하지 않는 개인 커밋이나 사후 작성한 문서를 당시 활동 증빙으로 만들지 않는다. 커밋 개수로 기여 비율을 계산하지 않는다.

## 자료 기준과 제출 전 확인

수집 88개, 공개·표시 검수 87개, 보류 1개다. 공식 썸네일 88개 중 공개 제품에 87개 연결했다. 정책 `2026-10-23.2`, 관심 분류 `2026-10-23.3`, 운영 AI `gpt-5.4` / COPA다. 공식 표시·가격의 주 관찰일은 10-19, 라벨 검수는 10-19~20, 썸네일 확인은 10-21이다. 문서 작성일을 상품 최신 확인일로 사용하지 않는다.

최신 제출 설명은 이 문서 묶음과 루트 README·기획서·명세서다. 이전 Gemini·초기 기획·canary 전환 기록은 당시 이력을 보존한 보조 자료다. [기준 정보·파일 해시](manifest.json)를 `python3 scripts/validate_final_docs.py`로 대조할 수 있다.

1. 실제 타깃 최소 5명의 참여 근거·날짜·질문·응답 원본을 익명화해 연결한다. 팀원은 제외한다.
2. 팀원 각자가 실제 수행 요약과 대표 커밋/PR/문서 링크를 확인한다.
3. 서면 심사용 발표 PDF를 제작해 목차와 README에 연결한다. 시연 영상은 선택하지 않았다.
4. 문서 변경을 `canary → dev → production` 절차로 저장·반영하고 플랫폼에 GitHub 저장소를 연결해 제출한다.

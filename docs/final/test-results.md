이 API 검사는 대표 사례이며 모든 화면 조작·모든 관심 조합을3회씩 검증한 것은 아니다. 다른 관심·포장 중복·특화 제한 등의 분류 회귀는 로컬 테스트와 [추천 연결 기록](../recommendation-v2-live-check.json)을 함께 본다. 명세의 화면별 재현 방법은 평가자가 직접 확인할 수 있게 기재했다.

이번 성공 사례의 소요 시간은 시작 질문7.19~11.32초, 추천12.78~15.65초였다. 단일 직렬 실행의 표본이며 부하 성능·SLA·최초 기동 시간 측정이 아니다. 캐시를 새 AI 생성으로 세지 않았다.

## 후속 로컬 화면 수정 — 제품 맥락 시작 질문

2026-10-24 canary 작업 폴더에서 제품 선택 시 시작 질문4개를 성분 역할·식사/섭취 시간·보관·일반 주의사항으로 교체했다. 일반 질문6개는 그대로다. 추천/비교/상세에서 선택한 제품 ID를 전달하는 기존 경로는 유지한다. 운영 배포 전 로컬 검증 기록이다.

- 실제 마그네슘 품번600000128로 네 질문 모두 GPT 답변과 해당 제품 인용을 확인했다. [실제 호출4건](evidence/product-context-prompts-local.json).
- 공개87개에 대해 질문 분류가 일반 정보 범위인지, 선택 제품 범위를 벗어나지 않고 표시를 조회할 수 있는지 확인했다. 섭취 시간·보관·주의 질문은87개 모두 직접 근거가 있다. 성분/기능 질문은77개 직접 검색, 나머지10개는 기존 상세 조회/표시 섭취 근거 경로가 가능하다. 기능 표시가 없을 때 효과를 만들어 내도 된다는 뜻은 아니다.
- 로컬 브라우저에서 제품 미선택의6개 질문, 상세의 ‘이 제품 질문하기’ 이후 제품 질문4개, 제품 맥락 제거 후 일반 질문 복귀를 확인했다. 제품 맥락 화면은 아래 기록에 있다.
- 프런트 자동 검사15개와 TypeScript/Vite 빌드가 통과했다. AI/DB 실행 코드는 변경하지 않았다.

## 후속 로컬 개선 — 주요 성분의 정량 카드와 쉬운 설명

2026-10-24 로컬 canary에서 성분 요약 답변을 함량·표시 기준치 비율 표 → 쉬운 설명 → 접힌 제품 표시/주의/근거 순서로 변경했다. 생성 숫자는 기존처럼 검사하고, 정량 카드는 서버가 DB에서 별도로 제공한다. 운영 배포 전 기록이다.

- 백엔드171개 통과(신규12개 포함), 프런트15개 통과, TypeScript/Vite 빌드 성공.

## 후속 로컬 개선 — 공식 성인 하루 섭취기준 대비 비율

이전 단계의 제품 표시 기준치 비율 UI를 성별·연령별 공식 RNI/AI 비교로 교체했다. 과거 API 증빙의 `percent`는 원래 제품 표시 값이며 새 계산에 사용하지 않는다.

- [공식 기준·계산 규칙](../adult-intake-reference.md):2025 한국인 영양소 섭취기준 요약표와 원문 SHA256을 확보하고25개 영양소·10개 성인군·250개 값을 대조했다.
- 프런트23개 검사·빌드, 백엔드 성분 요약 검사12개가 통과했다. RNI/AI 구분·성인군별 분모·질량/활동 단위·하루 분량·부등호·미지원 성분·100% 초과·아주 작은 비율을 확인한다.
- [브라우저 확인](evidence/adult-intake-reference-check.json): 기준 미선택은 계산 보류. 마그네슘315mg은 남자19~29세87.5%, 여자19~29세112.5%, 남자65~74세82.9%. 비타민D10μg은 앞 두 기준100%,65세 이상66.7%다. 임의로 비율을 낮추거나100%에 제한하지 않는다.
- 그룹 선택은 카드의 브라우저 메모리에서 처리하며 서버·외부 AI로 전송하지 않는다. 추천 정책·제품 DB는 변경하지 않았다.

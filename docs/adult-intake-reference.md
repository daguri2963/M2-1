# 성인 하루 섭취기준 비교

2026-10-24 · 로컬 canary 후속 개선. [최종 문서](final/README.md)

제품 주요 성분 답변의 비율은 **2025 한국인 영양소 섭취기준의 성별·연령별 권장섭취량(RNI), 없으면 충분섭취량(AI)**을 분모로 비교한다. 평균필요량(EAR)이나 상한섭취량(UL)을 분모로 사용하지 않는다. 개인의 필요량을 진단하거나 영양제로 채워야 할 부족분을 계산하는 기능이 아니다.

## 원문과 검수

- 발행: 보건복지부·한국영양학회,2025.
- [공식 배포 안내](https://www.kns.or.kr/fileroom/FileRoom_view.asp?BoardID=Kdr&idx=167)·[확보한 공식 요약표](../data/references/kdri-2025-summary-ko.pdf).
- 원문 확인일2026-10-24. PDF SHA256 `605ff8431ea7b6c465165bb5335aba580dcd4d56ba13a69583e62d163a7cc0c2`.
- [정규화 기준 데이터](../frontend/src/data/adult-intake-references.json): 영양소25개, 일반 성인군10개, 값250개. 각 영양소에 원문 PDF 쪽·인쇄 쪽·표 추출 행/열·RNI/AI 구분을 보존했다.
- 공식 요약표의 성인 열을 추출하고 PDF2·5·6·7·9·10·11쪽을 이미지로 렌더링해 열·단위·값을 같은 에이전트가 대조했다. 독립 임상 검토를 받은 자료라고 주장하지 않는다.

성인군은 남자/여자의19~29·30~49·50~64·65~74·75세 이상이다. 이는 공식 기준표의 구분이며 이용자의 성별·연령을 추정하지 않는다. 임신·수유·19세 미만은 이 비교 기능의 범위에 넣지 않는다.

## 계산과 화면

`제품의 표시된 하루 분량 속 성분량 ÷ 선택한 성인군의 해당 RNI 또는 AI ×100`으로 계산한다. 예를 들어 마그네슘315mg은 남자19~29세 RNI360mg 대비87.5%, 여자19~29세 RNI280mg 대비112.5%다. 비타민D10μg은19~64세 AI10μg 대비100%,65세 이상 AI15μg 대비66.7%다. 공식 값과 같으면100%가 나오는 것이 정상이며 수치를 일부러 다르게 만들지 않는다.

비교 기준은 기본 미선택이다. 사용자가 기준군을 선택해야 비율을 표시한다. 각 비율 아래에 분모의 종류·수량·단위를 함께 표시하며,100%에서 상한 처리하거나 색으로 안전/위험을 판정하지 않는다. 소수 첫째 자리로 반올림하고 양수0.1% 미만은0%로 오인하지 않도록 별도 표시한다.

- g/mg/μg의 물리적인 질량 환산만 허용한다. ug·µg·μg 표기를 정규화한다.
- RAE·NE·DFE·α-TE는 같은 활동 단위가 명시된 경우만 비교한다. IU·일반μg 등을 임의로 치환하지 않는다.
- 여러 정 기준은 그 표시된 하루 분량 전체로 비교한다. 칼슘4정 기준을1정으로 바꾸지 않는다.
- 총 포장 분량·섭취 기준 미확인·부등호 정량·단위 불일치·미지원 성분은 계산하지 않고 사유를 표시한다. 유산균·코로솔산 등에 임의의 성인 기준을 만들지 않는다.
- 제품에 원래 표시된 `percent`는 DB 원문 값으로 보존하며 새 성인 비율의 입력으로 사용하지 않는다. 원래 제품 표시 비율이 항상100%인 것은 아니다.

## 코드·개인정보·검증

[계산 함수](../frontend/src/adult-intake.ts)와 [화면](../frontend/src/ChatNutritionSummary.tsx)이 공식 데이터와 서버에서 받은 제품 정량을 대조한다. AI는 숫자·기준을 생성하지 않는다. 비교 기준 선택은 해당 카드의 브라우저 메모리에서만 처리하며 서버·COPA에 전달하거나 계정 프로필로 저장하지 않는다. 추천 정책과 제품 원본 DB는 변경하지 않는다.

[자동 검사](../frontend/tests/adult-intake.test.mjs)는 기준군별 분모·RNI/AI·질량 환산·활동 단위 경계·부등호·미확인·100% 초과·매우 작은 비율·원문 해시를 확인한다. 프런트 전체23개 검사와 빌드가 통과했다. 브라우저에서도 남자19~29세·여자19~29세·남자65~74세로 바꿀 때 비율과 분모가 갱신되는 것을 확인했다. [추가 검증](final/test-results.md)은 과거 제품 표시 비율 검증과 구분한다.

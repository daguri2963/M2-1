# 첫 질문의 근거 검색 오류 수정

수정일: 2026-10-21.

## 증상과 원인

제품을 선택하지 않은 AI 대화의 기본 질문 ‘함량과 기준량의 차이가 궁금해요.’가 `AI_NO_EVIDENCE`·HTTP503을 반환했다. 배포 화면에서도 같은 오류를 확인했다.

기존 검색은 상품 표시 원문과 상품명에 포함된 단어를 찾았다. ‘함량’, ‘기준량’은 개념을 설명하는 사용자 표현이며, 수치가 나열된 상품 원문에는 그 단어가 없어 로컬 검색 결과도 비었다. 일반 개념을 설명할 지식 경로가 없었고, 정상적인 검색 결과 없음도 서버 장애로 반환했다.

## 변경

- 함량·기준량·영양성분 기준치의 개념 질문에는 별도로 검토한 공식 안내를 검색한다. 기본 질문은 모델이 검색어를 잘못 고르더라도 질의별 서버 검색으로 근거를 확보한다.
- 일반 안내는 상품으로 위장하지 않으며 출처의 상품 ID/상세 URL은 null이다. 모델이 만들어낸 출처를 허용하지 않는 기존 검증을 유지한다.
- 제품을 선택한 질문에는 해당 상품의 영양정보·표시 섭취방법을 함께 검색한다. 일반 질문 때문에 임의의 제품을 추천하지 않는다.
- 일반 안내를 개인 추천 후보의 근거로 사용하는 것은 차단한다. 진단·필요량·용량 변경·개인정보 제한을 유지한다.
- 실제로 근거가 없으면 HTTP200의 질문 구체화 안내를 표시한다. 공급자 장애·키 미설정·한도 등은 기존 오류로 남긴다.

## 자료 범위

`backend/label-guides.json`의 요약은 작성 후 공식 원문과 대조했다. 개별 상품 검수나 영양학적 임상 검증과는 구분한다.

- [FDA 소비자 안내](https://www.fda.gov/consumers/consumer-updates/fda-101-dietary-supplements): serving size와 amount per serving의 구별에만 사용한다. 미국 법적 표시 요건을 국내 상품에 적용하지 않는다.
- [식품안전나라 영양표시 FAQ](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?bbs_no=bbs423&menu_grp=MENU_NEW03&menu_no=3717): ‘영양성분 기준치’ 항목의 비교 목적·평균적 기준 개념만 사용한다. 과거 표시 법령·숫자·의무 요건은 가져오지 않는다.

정의 안내와 상품별 수치/섭취 지시를 구분한다. 제품별 기준량·함량·섭취방법은 실제 검수 표시를 확인해야 한다.

## 확인

- 백엔드 전체35개 통과: 기본 문구·띄어쓰기·기준치 변형, 선택 제품의 표시 근거 동시 조회, 모델의 빈 검색에도 기본 질문 근거 유지, 일반 안내의 추천 근거 혼입 거부, 근거 없음200/공급자 실패503 구분을 추가했다.
- 프런트10개·TypeScript 검사·프로덕션 빌드 통과.
- 실제 Gemini로 기본 질문을 보내 약2.4초에 공식 안내 출처2개와 개념 설명을 받았다. 상품 선택 없이 답했으며 상품 ID는 빈 목록이었다. 이는 단일 실행 사례이며 응답 시간 보장값이 아니다.

- 수정 커밋 `c8fa914815cf883d47d22619c5b691a55c7bd0d5`로 홈페이지·백엔드를 재배포하고 양쪽 `live` 상태를 확인했다.

- 기존 탭은 새로고침 후 다시 동의해야 할 수 있다. 서버 재배포로 메모리 세션이 초기화되기 때문이다.

# 기능 요구 명세서 — 최종 구현 기준

2026-10-24 · 코드 `0bc17dc` · [제출 목차](final/README.md)

Must는 **8개**다. M08은 초기 외부 대안 제품 구상이므로 번호만 비워 두고 구현·평가 범위에 넣지 않는다. AI 비교 해설은 Should S01이다. 하위 확인 항목을 숨겨 Must 개수를 축소하지 않으며, 아래 기대 결과 전체가 각 기능의 범위다.

## 사용자와 입력

일반 성인의 제품 탐색을 지원한다. 계정 가입은 없다. 공개 제품은 87개다. 관심 분야는 일상의 활력·뼈·근육 건강·장 건강·혈당 관리·다이어트다. 눈 건강·다양한 성분 보기·관심 분야 모름은 지원하지 않는다. 식습관·기존 제품·주의조건의 모름 선택은 유지한다.

설문은 ① 관심 ② 식습관 ③ 기존 제품 ④ 주의조건 ⑤ 선택 예산/제형 순이다. 기존 제품은 등록 DB에서 최대 10개를 선택하거나 없음/모름/목록 밖을 구분한다. 병명·약품명·검사값은 입력받지 않는다. 혈당·다이어트에는 별도 범위 확인이 필요하다.

| 화면 | 구성·주요 조작 | 다음 이동·비정상 상태 |
|---|---|---|
| 홈 | 추천 시작, 제품 탐색, 비교, AI 진입 | 동의 필요 기능은 이용 안내로 연결 |
| 설문 | 단계 표시·선택 카드·이전/다음·선택 항목 건너뛰기 | 필수 누락 차단, 이전 이동 시 값 유지, 관심 선택 어려우면 AI 안내 |
| 추천 결과 | 최대 3개 후보·이유·성분·제한/부족 안내·조건 수정 | 상세/비교/대화, AI 해설 실패 시 후보와 오류를 구분 |
| 제품 찾기/상세 | 검색·필터, 공식 사진, 관찰 가격, 전체 표시·출처 | 없는/보류 제품은 찾을 수 없음. 공식 페이지로 근거 확인 |
| 비교 | 두 제품 선택·교체·AI 해설·전체 표·차이 보기 | 세 번째 선택은 교체 확인. AI 오류가 나도 표시표 유지 |
| AI 대화 | 시작 질문·입력·답변·인용·재시도 | 제품 문맥 진입, 정보 부족 안내, 개인 판단 요청 제한 |

모바일에서는 짧은 요약 후 상세 정보를 펼치도록 구성한다. 서버 기동 대기와 AI 생성 중을 구분하며 재시도·조건 수정 경로를 제공한다.

응답 시간의 고정 SLA는 설정하지 않았다. API 제한값은 서비스 내부 보호 장치이며 지원 사용자 수·공급자 한도 보장이 아니다.

## 평가 재현 공통 조건

[운영 서비스](https://vitastep-guide.onrender.com/)에 접속해 필요한 동의 3개를 확인한다. 테스트용 가상 성인 선택지만 사용하고 실제 건강정보를 입력하지 않는다. 각 Must를 아래 화면 조작으로 3회 확인하며 2회 이상 기대 결과인지 기록한다. API 반복 검사와 브라우저 검사의 범위·결과는 [검증 결과](final/test-results.md)에 분리했다. 데이터 변경 시 아래 품번 예시는 다시 확인한다.

### 설문 선택지 후속 정리 (2026-10-24, 로컬 카나리)

- 3번 기존 제품 질문은 `없어요`·`제품 선택`만 제공하며, 제품 표시 안내 아래에 다이소 외 제품은 비교하지 않는다고 명시한다. 제품 선택 시 실제 목록에서 하나 이상 선택해야 다음 단계로 진행한다. 검색 결과가 없으면 검색어 재확인과 지원 범위를 안내하며, 삭제한 선택지로 유도하지 않는다.
- 4번 주의조건 질문에서 `잘 모르겠어요`를 제거한다. 진단명·약품명 입력이 필요 없다는 안내 아래에 1~3번 항목 선택 시 전문가 상담이 필요해 추천하기 어렵다고 표시한다. 해당 조건의 기존 서버 추천 제한은 유지한다.
